# evolve

## Local EVOLVE presenter

From the repository root, run `uv sync`, then `uv run python -m factory.lab`. Open [the local presenter](http://127.0.0.1:8765). Fresh builds use the presenter's authenticated Codex CLI and require its model connection. The scientific app executes offline under macOS Seatbelt or Linux bubblewrap. EVOLVE uses local records under `runs/b12` and does not call 8090.

Submit a B12 request and inspect the task ID, actual worker receipt, source revision, generated files and independent tests. The simulated instrument implements 550 nm. Previously completed runs remain accessible on the presenter. The existing static EPR workbench is available with `npm run dev`.

Run the test suite with `uv run python -m unittest discover -s tests -v`. In an environment that forbids nested sandboxes, run the tests directly on the host so the scientific runner can apply its own restrictions.

For the follow-up, open the above-range finding, inspect the evaluation agent’s protocol-based proposal and approve it. Record 1 mL sample and 2 mL final volume while the worker builds prepared-sample support. Compare the parent and child checks and their source diff. When both prerequisites are ready, run the diluted vial, reveal the original preparation, replay both acquisitions and download the reproducibility package. The recommendation is generated by a bounded protocol rule. The source change is generated by the local coding worker.

### Rehearse the demonstration

Open the local presenter to start a fresh build. During generation, select a previous completed run and use **View fresh task** to return to the live build. The static workbench also includes a saved B12 run at `/b12/`, which exports to `out/b12/index.html`. It shows the actual revisions and measurements from the rehearsal. To reproduce both outputs from the downloadable package on a machine with the offline runner, execute:

```sh
uv run python -m factory.replay_bundle public/b12/completed.json
```
