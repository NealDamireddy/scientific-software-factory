Do not release the shared entry for SRM 2686b. Give bulk MgO and periclase separate constituent IDs because the methods report different quantities.

| Chart | Quantity | Target (mass %) | Status and uncertainty |
|---|---|---:|---|
| XRF | Bulk magnesium reported as MgO | 4.37 | Information value from certificate Table 3. No expanded uncertainty is stated. The value cannot establish metrological traceability. Leave the chart allowance unset. |
| Diffraction | Periclase phase abundance | 3.31 | Certified value from certificate Table 1. Record ±0.70 percentage points as the expanded uncertainty (k = 2). Set any chart control limits separately. |

XRF reports bulk magnesium on an oxide basis, while diffraction quantifies the periclase phase. The ±0.70 percentage points applies to the certified periclase value and provides no basis for an XRF allowance.

The April 2021 characterization report’s abstract describes periclase as a diffraction-only reference value. For the 15 September decision, the 9 July 2021 certificate establishes its certified status using combined powder diffraction and electron microscopy/image analysis. The earlier abstract therefore does not support treating the diffraction entry as provisional.
