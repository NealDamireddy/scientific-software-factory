Use assignments on a common carbon scale for all normalization materials and record the assignments and scale on the worksheet. If the worksheet requires VPDB, obtain a documented VPDB assignment before using IAEA-600 for that normalization. The issuer notes that the separation between VPDB and VPDB-LSVEC varies with isotopic composition. (IAEA-600 reference sheet, revision 0, 25 September 2025, pp. 1–4, records 01 and 02.)

The draft carbon value of −27.73 ± 0.07‰ comes from the EA-IRMS study, where ±0.07‰ is the half-width of a 95% confidence interval. The issuer’s table supplies the carbon reference value and classifies the matching oxygen number as an information value. A certification claim would require an applicable issuer document explicitly certifying the property for the material in use. (EA-IRMS normalization study, Table 1, record 03, and IAEA-600 reference sheet, pp. 1–2, record 01.)
