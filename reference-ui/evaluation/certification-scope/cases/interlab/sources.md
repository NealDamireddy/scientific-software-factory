# USGS water laboratory comparison

The historical record is the U.S. Geological Survey’s interlaboratory evaluation of water samples distributed in April 2001, Open-File Report 2001-287. The intake question, draft register entry and migration scenario were constructed for this exercise. The laboratory identifiers and results are those published in the report. [USGS publication record](https://pubs.usgs.gov/publication/ofr01287) · [USGS report](https://pubs.usgs.gov/of/2001/0287/report.pdf)

The issue note summarizes the abstract, statistical presentation of data, and laboratory ratings. Both CSVs transcribe selected entries from Table 12, M-158 chloride, including the publisher’s displayed precision. Code 7 denotes ion chromatography and code 20 denotes colorimetric titration. Table 6 independently lists lab 105’s chloride result and rating. The packet contains one publication and no separate certificate or uncertainty budget. Its limits apply to this evidence selection.
