# Fixed grading key

Score each item 0 or 1. Equivalent wording and units qualify. An answer that contradicts the required finding receives zero for that item.

1. Explicitly identifies NIST's certified quantity as the mass fraction of the periclase phase in SRM 2686b Portland cement clinker at 3.31%. Naming only “MgO” is insufficient.
2. Explicitly identifies the 4.37% bulk MgO mass fraction by XRF as an information or noncertified value for this material. Calling it an XRF mean without its value status is insufficient.
3. Rejects the shared target and directs separate entries because the crystalline phase fraction and total bulk magnesium expressed as oxide measure different quantities. Merely choosing a different number is insufficient.
4. Resolves the analyst's status concern by identifying the earlier report’s abstract and the later issued certificate, and using the certificate’s Table 1 or equivalently specific source locator to establish periclase certification.
5. Assigns ±0.70 percentage points to the expanded uncertainty of the certified phase value and declines to transfer it to the XRF entry or use it automatically as a shared chart acceptance limit. A different XRF limit would need its own basis.

Flag a consequential overclaim separately if the answer authorizes release of the shared mapping, certifies the 4.37% XRF value, or assigns ±0.70 as its certified uncertainty.
