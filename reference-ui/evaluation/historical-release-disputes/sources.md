# Sources and evidence cutoffs

The reviewer packets contain short verbatim decision requests and condensed contemporaneous evidence. Names, email addresses, personal signatures, institutions and external links were removed from the packets. No human subjects are involved. Scientific identifiers, dates, units and uncertainty values were preserved. The sources below identify the original public correspondence. Redaction of the packets does not render the public sources anonymous.

These are public decisions about the release or correction of environmental laboratory data. They do not contain an internal supervisor’s complete accession, instrument and QC archive. The packets contain curated evidence available by each cutoff, not a claim to reconstruct everything the original people knew. Modern corrected files were excluded. The permission to release a dataset in C is distinct from the issue about the data quality of that release.
