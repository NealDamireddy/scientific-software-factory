# Station 716 · request received 9 January 2004

> How do we go about resolving this?

The investigator is questioning nitrite for bottles 6, 5 and 4 at approximately 2818, 3179 and 3538 dbar. All three concentrations exceed 2.5. The investigator expected near-zero concentrations at these depths and believes all three quality flags read 2, but is unsure they counted the flag positions correctly.

Available archive entries:
- September 1999: A processor recorded changing nitrite to 0.01 for station 716, bottles 4, 5 and 6, following instructions received by email. The entry also documents formatting and cruise-code changes to a summary file.
- 2001: A replacement bottle data file was submitted for a temperature calibration correction.
- May 2003: A processing-history entry again records the 0.01 edit for the same station and bottles. Its wording about the edit repeats the earlier entry.
- September and November 2003: Further merges are recorded. The November work concerned CFCs and flag handling for that merge. None of these pre-request entries states which merge caused the currently observed nitrite discrepancy.
