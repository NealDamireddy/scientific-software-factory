# Groundwater monitoring report · original regulator request

> The data validation memoranda and the text should be consistent.

This is a written oversight request in a comment exchange on the December 2001 monitoring report. The regulator states that the report text and Table 5 classify all target volatile-organic results as estimates because adequate preservation on receipt was undocumented. The associated validation memo says that an earlier qualification was subsequently removed. According to the comment, the removals included samples analyzed May 3 and May 6, 2001 without new confirmation of sufficient acidification.

The regulator requests continued estimated status unless the laboratory can confirm pH below 2. Their concern is that adding preservative in the field might have been omitted or might have been insufficient. The later reply to this comment and its attachments are outside this packet.
