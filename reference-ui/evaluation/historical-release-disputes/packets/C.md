# Bottle-file review · request received 13 February 2001

> The question is whether or not it would be possible to track these QC flag errors down and get another, corrected file.

On one row the instrument oxygen field (CTDOXY) is −9.0 but its flag reads 2, good. The instrument salinity field (CTDSAL) on that same row has a numeric measurement but the corresponding flag indicates a missing value. The reporter saw more inconsistencies near the beginning of the file.

Before the request, the originator supplied the water-sample measurements as an Excel file in November 2000 and authorized public distribution. A separate November processing entry reports successful plotting and format checks of instrument profile files.

Applicable reporting specification, revision 2, February 1998, chapter 4: The bottle identifier takes the first independent position in the bottle file's quality string. If measured, instrument salinity and instrument oxygen take the next positions. The subsequent positions describe the water-sample measurements. The bottle, instrument and water-sample flag definitions differ.
