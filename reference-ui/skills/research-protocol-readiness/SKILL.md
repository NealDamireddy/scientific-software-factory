# Run setup completeness

## Evidence to gather

Run objective, project, method revision and the measurement settings required by that method.

## Review procedure

1. Establish the intended measurement before execution. Read the saved objective, project, and versioned method reference. From the supplied method, identify the fields essential to interpreting this measurement. For the illustrative absorbance methods, the briefing includes a wavelength in nm. For a different method, use its stated requirements and units.

2. Inspect each required field for presence and meaning. Record the field, value, unit, and applicable method clause where available. A positive wavelength makes that field usable; it does not establish that the method calls for that wavelength. A missing wavelength leaves the check unassessed. A recorded value of zero nm is a concrete finding. If a referenced method is unavailable, report which briefing checks you completed and which method-specific checks need its text.

3. Return a readiness note with the required field that needs attention, the evidence, and the smallest clarification that would settle it. If all supplied checks pass, state their limited scope. Keep this decision advisory and leave starting the run to the existing approval flow. On a revised draft, compare changed fields with the original finding and retain any still-open gaps.

## Expected result

Briefing readiness with field references and any missing or invalid setup.
