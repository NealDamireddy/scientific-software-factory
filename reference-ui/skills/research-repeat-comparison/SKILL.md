# Repeat comparison

## Evidence to gather

Linked original and repeat records, comparable measurements and the authorized change.

## Review procedure

1. Establish the lineage of the repeat. Find the explicitly linked original run, the reason it was flagged, the reviewer’s decision, and the repeat it authorized. Match sample identifiers when the records supply them. A neighboring run in a list is insufficient to establish that link. If the predecessor or approval is ambiguous, stop the authorization check and cite the unresolved link.

2. Compare what was requested, what was authorized, and what the repeat records as performed. Cite factors, units or changed conditions alongside both run IDs. Use each run’s own standards and method revision to evaluate its outcome. An in-range repeat at a recorded fourfold dilution can still conflict with approval for a twofold dilution. Conversely, a repeat can follow the approved change and still yield an out-of-range reading.

3. Return two conclusions: whether the documented change matches the approval, and whether the repeat addresses the original finding. Mark either unassessed when its evidence is missing. Cite the decision and both observations and keep an unresolved discrepancy visible even if the other check passes. A single repeat establishes the outcome of that repeat; use a separate study design to assess broader reproducibility. On rereview, update the finding for this run pair while preserving its approval trail.

## Expected result

A comparison of expected and observed changes with citations and unresolved differences.
