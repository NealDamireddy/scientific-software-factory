# Method reference

## Evidence to gather

Method name and revision from the run briefing.

## Review procedure

1. Identify the method for this run. Start with the original or repeat run’s saved briefing. Extract the exact method name and revision. If a method record is linked and supplied, follow that link and compare its identifier and revision with the citation. Treat titles found by text similarity as possible matches only.

2. Judge identification separately from content. A name and revision establish what the briefing cites. Claim that a clause was inspected only when its versioned text is available. For example, a briefing that says “Absorbance method v1.0” can identify v1.0 even when the library now displays v2.0. If two supplied records plausibly match the same citation, leave the target unresolved and identify both candidates.

3. Return the run identifier, cited method and revision, and the record or field that supports each. Mark a blank revision unassessed. When a supplied linked revision conflicts with the briefing, anchor the finding to the inconsistent reference. Suggest that the researcher identify the intended record. On rereview, compare the same citation and carry forward existing findings once per affected field. Preserve the as-run citation.

## Expected result

Method identification status with the available briefing references.
