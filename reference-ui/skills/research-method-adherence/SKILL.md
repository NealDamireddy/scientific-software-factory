# Method adherence

## Evidence to gather

Versioned method clause, observations for this run, and the reported decision.

## Review procedure

1. Select one explicit obligation from the method revision associated with this run. Identify its trigger, required behavior, and the run record where the behavior would be observable. If the method text is unavailable, assess only rules explicitly supplied for this fixture. State their scope.

2. Compare the observed decision to that obligation. In the illustrative B12 workflow, an out-of-range reading requires concentration to be withheld. A flagged measurement with an explicit withholding decision follows that rule. A numeric concentration for the same out-of-range reading contradicts it. An absent result field leaves the decision unknown. Treat ambiguous or missing evidence separately from a demonstrated contradiction.

3. For each contradiction, anchor one finding to the affected decision and cite the method clause and run evidence. Explain the expected and observed behavior in language a researcher can check. If the supplied decision is consistent, record the checked scope without adding an issue. On rereview, identify the prior finding by run, rule and affected field. Update the advisory status only when new evidence addresses it. Preserve human comments, approval history, and the original measurement.

## Expected result

A cited assessment of whether the recorded decision follows the identified clause.
