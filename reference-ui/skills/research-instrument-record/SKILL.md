# Instrument record

## Evidence to gather

Equipment reference, applicable method, operating settings and the associated run record.

## Review procedure

1. Trace the measurement to the equipment identified at run start. Use the instrument field captured with the run. If it carries a stable instrument or asset ID, use that ID to locate a supplied inventory record. Record a human-readable label at the level of specificity the evidence supports.

2. Cross-check the recorded instrument, method, and measurement setting against the supplied records. For an absorbance run, cite the recorded wavelength and its unit. A briefing can name a UV–Vis spectrometer without identifying which physical unit was used. If an inventory lists two instruments with that label, report the identity ambiguity. A current inventory entry alone cannot establish historical availability, maintenance status, or which instrument produced a reading.

3. Attach the identification result to the run’s instrument field. Cite the matching ID if present and identify the exact missing detail when stronger provenance is needed. Flag an observed identifier conflict separately from missing context. On rereview, reconcile the previous finding against the same run and the newly supplied evidence. Leave historical readings and equipment settings intact.

## Expected result

A cited start-record check identifying any missing context.
