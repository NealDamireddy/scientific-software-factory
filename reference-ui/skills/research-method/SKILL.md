# Method comparison

## Evidence to gather

Two method records

## Review procedure

1. Identify the two method records requested for comparison. Capture both revision labels and their sources. Prefer the snapshots tied to the two runs. If only today’s library version is supplied, identify the missing historical version and leave its changes unassessed.

2. Align fields by scientific meaning. Compare measurement conditions, units, analysis equations, applicability ranges, and reporting rules to the extent recorded. Separate a unit conversion from a physical change, a wording change from a new requirement, and an omitted field from a known deletion. For example, 0.595 µm and 595 nm represent the same wavelength. A change to a dilution used in one repeat belongs to execution history unless the method revision itself changes.

3. Report before and after values with both references. State how a material difference could affect comparison of the results, and label its actual effect unknown unless run evidence establishes it. If two records carry the same revision label but disagree on a field, surface the identity conflict for the method owner. On rereview, retain one observation for each revision pair and changed field. Leave selecting an approved revision to the researcher.

## Expected result

A list of changes to parameters and interpretation
