# Evidence summary

## Evidence to gather

Run history, source readings, and reviewer decisions

## Review procedure

1. Begin with a specific result or reporting decision and its run identifier. Work backwards through the supplied evidence to the sample and raw observations, the measurement context, the versioned method, and any decisions linking one run to another. Keep references local to the run unless an explicit relationship identifies a predecessor.

2. Reconstruct the sequence using recorded facts. Keep raw values, derived values, reviewer decisions and agent findings distinct. For a time course, cite the recorded time unit and the points supporting any claimed trend. Endpoints alone support an endpoint change; they cannot establish a monotonic trace. For a diluted repeat, distinguish the measured sample concentration from the original concentration reported after correction.

3. Write a short account in which each consequential claim has a source field or record reference. Mark gaps explicitly, including a missing reviewer decision or unidentified instrument when relevant to the requested claim. A connector listed in a run briefing is configuration metadata; count retrieved records as evidence only when they are actually supplied. On rereview, preserve earlier summaries and identify which new or corrected evidence changed the conclusion.

## Expected result

A summary with references to the underlying records
