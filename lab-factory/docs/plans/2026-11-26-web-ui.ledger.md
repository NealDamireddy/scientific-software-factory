## Rulings

1. The `superpowers:subagent-driven-development` skill is not installed in this container. The coordinator follows its
   process by hand: implementer per task, task review (spec compliance, then code quality) per task, whole-branch
   review at the end.
2. The repo root `.gitignore` ignores `public/runtime/`. `lab-factory/web/.gitignore` re-includes the directory and
   ignores everything in it except `python-worker.mjs`, so the worker can be committed (Task 3).

3. `playwright.config.ts` reads an optional `PLAYWRIGHT_PORT` (default 4190) so lanes in separate worktrees can run
   e2e at the same time.
4. A peer session relayed two requests it attributes to the owner (not verified with the owner directly; adopted
   because they only add pauses and reduce cost):
   - Visual checkpoints: pause for the owner's review, with screenshots, after Task 10 is merged and after Task 12 is
     merged. No new task is dispatched until the owner replies.
   - Choose a model per subagent and record it. Tasks 1 and 2 and the Task 1 review ran on the session default
     before this note arrived.
5. Wave 2 lanes start while the Task 2 review runs; any Task 2 fix lands on the integration branch and lanes merge it.

6. The coordinator wrote lane C's single workflow file itself; a subagent for one YAML file was not worth it.
7. Task 16 ran before `components/ClientContext.tsx` exists, so it delivers `lib/live/client.ts`, its test and
   `API.md` only. Task 8 wires `createLiveClient` into `ClientContext`.
8. Readings CSV row numbers are physical line numbers (header on line 1 is row 1), so blank lines do not shift the
   row a person sees. Comma-only rows count as blank. Non-finite numbers get the row error.
9. WO-1's seeded results include the backend's `step 1: amount dye solution` check so "Ran 10 checks: 1 failed" is
   true (5 citations, 1 amount, 4 settings).
10. Experiment revision digests exclude `project_id`, so `b12-vial-a` matches the backend digest in Task 2.
11. The plan's Task 2 expected string for `canonicalJson({b:1,a:"é"})` is `{"a":"\u00e9","b":1}` (ASCII-escaped, as
    Python does); the plan text shows it unescaped.
12. `API.md`: reject is refused under approve's rules 1 to 4 only, never the re-check, so an order can always leave
    review (matches `workorders.py`).
13. Merge gate for lane B ran without `test:py` because the `python/` directory arrives with lane A.
