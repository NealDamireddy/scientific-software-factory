A software factory for lab instruments

When the experiment changes, the lab needs different software. EVOLVE can prepare that software while the instrument collects data.

0:00–0:25. “I’m Neal, a physics student in a biophysics lab at Emory. One student might measure how a sample changes with temperature. Another might use the same instrument to follow it over time. The equipment is shared, but someone still has to write the software for each question. This recorded example shows the workflow I wanted: the factory was already building the app when the measurements started.”
