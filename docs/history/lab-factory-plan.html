Factory design
What the lab owns
EVOLVE runs independently of 8090. A PI’s request creates a scientific software task inside EVOLVE. The lab can build and run an assay with 8090 disconnected.

  

    
Trusted factory
The instrument registry, simulator, approval record, frozen calibration, independent tests and evidence store belong to EVOLVE. The factory checks the recipe at construction and again at acquisition.

    
Local coding worker
EVOLVE sends the worker the approved capability and public contracts. The host stages candidate files in isolation. Hidden labels, validator writes and calibration writes are outside the worker’s access.

    
Generated assay app
Each revision supplies analysis source, an acquisition recipe and app controls. The host returns a task ID, the source revision, a diff and test results. A different vial name or supported factor reuses v2.
