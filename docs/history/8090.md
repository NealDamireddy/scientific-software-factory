# EVOLVE engineering project

The repository-linked [EVOLVE project](https://factory.8090.ai/project/57fbf0e2-015b-4e28-93cd-ae06b55fadc4) tracks development of the lab factory. Its [B12 requirements](https://factory.8090.ai/project/57fbf0e2-015b-4e28-93cd-ae06b55fadc4/requirements/e21cd0b8-7231-4138-ae1e-fd411833324d) and [component blueprint](https://factory.8090.ai/project/57fbf0e2-015b-4e28-93cd-ae06b55fadc4/blueprints/e406f284-f7d5-47e9-be16-7e0586f6059d) govern WO-1 through WO-5. Scientific tasks at runtime use local EVOLVE IDs.

## Historical EPR prototype project

The following records describe the earlier EPR work in a separate project. Its work-order numbers are local to that project.

The signed-in hackathon workspace created a Requirement, a Component Blueprint and five Build Work Orders on November 13. The demo orders were adapted from the observed WO-2 title and acceptance criteria. The integration boundary is a structured import. The connected browser was used for project planning. The CLI can also adapt an exported Work Order CSV with ID/Number and Name/Title columns.

| ID | Scope |
|---|---|
| WO-1 | Register the shared simulated EPR lab and two project contexts |
| WO-2 | Generate offline Python applications for Gaussian linewidth and Curie fitting |
| WO-3 | Verify capabilities, units, metadata and numerical references in an isolated runner |
| WO-4 | Publish an interactive Next.js/Vercel evidence workbench |
| WO-5 | Package the MIT repository and rehearse the five-minute demo |

WO-2 specifies a derivative linewidth of 0.8 mT for σ = 0.4 mT, with a 0.002 mT tolerance, including the equivalent field grid in G. Its inverse-temperature reference has C = 120 a.u. K and b = 0.25 a.u. Code generation can use the network. Scientific execution runs offline.

Project members can open the [requirement](https://factory.8090.ai/project/89b2fbf5-5ea2-465f-a68b-6d56ca7c4078/requirements/cc2a10cd-9a8e-4708-bab6-8317c6cd54d2), [blueprint](https://factory.8090.ai/project/89b2fbf5-5ea2-465f-a68b-6d56ca7c4078/blueprints/58b5ed0c-5cb0-498a-91d0-d359dd068fce) and [WO-2](https://factory.8090.ai/project/89b2fbf5-5ea2-465f-a68b-6d56ca7c4078/work-orders/2).
