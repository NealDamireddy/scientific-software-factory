## Contracts

A work order identifies the registered lab, project, instrument, dataset, units, requested operations, processing parameters, objective, behavior, acceptance criteria, verification requirements and human review. The JSON Schema is in registry/. Resolution returns a snapshot of one project's inherited context. Accepted code reads a two-column CSV from stdin and emits one numeric JSON object on stdout. Each run directory contains snapshots and a report with individual pass, fail, unknown and untested outcomes plus SHA-256 artifact digests.
